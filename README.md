# Sujithra Balasubramani — Portfolio

A static portfolio site for **Sujithra Balasubramani**, Lead UI/UX Designer.

## What's in here

- **`index.html`** — main landing page (case studies grid, about, contact)
- **`freelance.html`** — freelance brand work showcase (10 brands)
- **`arcone-case-study.html`** — ArcOne AI case study
- **`warehouse-case-study.html`** — BigBasket Warehouse Management case study
- **`ati-case-study.html`** — ATI Physiotherapy Appointment Finder case study
- **`bill-compare-case-study.html`** — Bill Compare case study
- **`*_assets/`** — images, logos, screenshots, resume PDF

## Run locally

Just open `index.html` in a browser. Everything is static HTML/CSS/JS — no build step.

```bash
# optional: serve locally with python
python3 -m http.server 8080
# then open http://localhost:8080/
```
